# Marca de Calzado Guibol

> Dirección del demo: **cuero premium, editorial cálido**. Ver `docs/MARCA.md` para el detalle.

## Paleta

| Uso | Hex |
|---|---|
| Primario, cuero coñac | `#8A4B2A` |
| Acento, cuero claro | `#B07A49` |
| Autoridad, carbón | `#1C1917` |
| Fondo, marfil | `#F5F0E8` |
| Texto secundario | `#4A4038` |

Tema oscuro: fondo `#17120F`, superficie `#241D18`, texto `#F5F0E8`, acento `#DFB184`.
Los componentes usan variables semánticas de `src/styles/global.css`; no cambiar colores
en los archivos `.astro`.

## Tipografías

- Títulos: **Fraunces**, archivo local `public/fonts/fraunces-normal.woff2`
- Cuerpo: **Manrope**, archivo local `public/fonts/manrope-normal.woff2`
- Ambas auto-hospedadas, sin Google Fonts.

`CALZADO EN CUERO` debajo. Favicon provisional: monograma G sobre carbón

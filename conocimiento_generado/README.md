# Conocimiento del sitio — Calzado Guibol

Estos ocho archivos describen qué hay en el sitio y cómo se cambia. Léelos completos antes
de editar nada.

| Archivo | Para qué |
|---|---|
| `SITIO.md` | Qué es el negocio, qué páginas tiene y datos de contacto |
| `SECCIONES.md` | Dónde vive cada texto y sus límites |
| `COMO-EDITAR.md` | Recetas de los cambios más comunes |
| `MARCA.md` | Colores, tipografías y tono |
| `STACK.md` | Con qué está hecho y dónde está cada cosa |
| `PUBLICAR.md` | Cómo ver cambios y cómo publicar |
| `PENDIENTES.md` | Lo que quedó a medias o es de muestra |
| `LIMITES.md` | Qué no se toca y cuándo llamar al proveedor |

Regla del sitio: **en los `.astro` no se escribe texto. Todo el contenido vive en `src/datos/`.**
